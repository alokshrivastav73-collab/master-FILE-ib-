How to Use

  1. Dockmaster: Appointment Browser → Status Closed → select date → required columns → Submit → Export CSV → upload the CSV here.
  2. YMS: Yard Management → Event History → Event Type = PRE_CHECK_IN only → select date → ISA NO only → export CSV → upload here.
  3. JIRA ISA (Optional): Upload JIRA file (filtered by FC code) or paste ISA numbers directly into the JIRA box.
  4. Processing: Appointment ID is matched with YMS ISA. The YMS UTC timestamp is converted to IST (+5:30).
  5. Status: If PRE CHECK-IN − ISA APP is ≤ 30 minutes → On Time; otherwise → Late.
  6. TAT Miss Logic: On Time > 3 hrs = TAT Miss (else Not Miss); Late/Sideline > 10 hrs = TAT Miss (else Not Miss).
  7. Dockmaster Required Columns: Appointment Id | Type | Carrier | CRDD | Schedule Date | Expected Arrival Date | Timer(HHH:MM) | Percent Need | Priority Score | Priority Score Last Updated Date | Status | Pallets | Cartons | Units | Dock | CheckIn Date | Closed Date.
