How to Use

  1. Dockmaster: Appointment Browser → Status Closed → select date → required columns → Submit → Export CSV → upload the CSV here.
  2. YMS: Yard Management → Event History → Event Type = PRE_CHECK_IN only → select date → ISA NO only → export CSV → upload here.
  3. JIRA ISA: Paste/upload the ISA list from the TAT Report sheet.
  4. Processing: Appointment ID is matched with YMS ISA. The YMS UTC timestamp is converted to IST (+5:30).
  5. Status: If PRE CHECK-IN − ISA APP is ≤ 30 minutes → On Time; otherwise → Late.
  6. Sideline/JIRA: If Appointment ID exists in the JIRA ISA list → that ISA is marked as Sideline/JIRA; otherwise NOT SIDELINE.
  7. TAT: On Time = Closed − ISA APP. Late = Closed − PRE CHECK-IN.
  8. Dashboard: ONTIME and LATE use the workbook's 95th percentile logic; targets are 3 hrs and 10 hrs. Sideline target is 10 hrs.

Important: There is deliberately no OSSLA calculation in V2.
